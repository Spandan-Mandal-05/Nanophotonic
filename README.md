## Project Overview

This project investigates polarization-dependent transverse beam shifts
arising from the Spin Hall Effect of Light in dielectric metasurfaces.

The electromagnetic response was modeled using finite-element simulations
in COMSOL Multiphysics, followed by Python-based data processing and
visualization.

## Methods

- Finite-element electromagnetic simulation
- Maxwell's equations
- Floquet-periodic boundary conditions
- Parameter sweeps
- Grid convergence analysis
- Python-based data processing
- Numerical analysis
- Scientific visualization

## Parameter Space

- Wavelength: 370–1110 nm
- Incidence angle: 0.5°–10°
- Asymmetry parameter: α = 0–1
- Materials: amorphous and crystalline Sb₂S₃

## Results

The simulations revealed strong polarization-dependent beam shifts near
resonant conditions. The analysis included normalized SHEL shifts,
reflectance efficiency, angular dependence, and parameter-dependent
behavior.
